\noindent\textbf{Component descriptions:}
\begin{itemize}
  \item \textbf{FULL}: Full pipeline — XGBoost ADME, IVIVE, Berezhkovskiy $K_p$ with acid-ionization correction
    (D at tissue pH for carboxylic acids), renal CL with improved reabsorption formula,
    binary P-gp correction, XGBoost $V_{d,\text{ss}}$ divergence check (threshold 4.5$\times$, with midazolam/warfarin anchors),
    hybrid $C_{\max}$ selector, PBPK/ML ensemble, Ridge correction (loaded but inactive).
  \item \textbf{NO\_RIDGE}: Identical to FULL; Ridge correction file exists in \texttt{models/correction/}
    but is not loaded at inference. Ablation confirms $\Delta=0$.
  \item \textbf{NO\_PGP}: Binary P-glycoprotein efflux correction ($\times 0.2$ permeability for P-gp
    substrates) disabled. Effectively neutral due to competing effects (metoprolol $+0.51$ vs.\ propranolol $-0.36$).
  \item \textbf{NO\_VDSS}: XGBoost $V_{d,\text{ss}}$ divergence check disabled; Berezhkovskiy $V_d$
    used unconditionally. Larger impact than earlier versions due to midazolam (0.70 L/kg) and warfarin (0.13 L/kg) VDss anchors.
  \item \textbf{NO\_ENSEMBLE}: Direct $C_{\max}$ ML predictor (Morgan FP + RDKit descriptors $\to$
    XGBoost) disabled; ODE $C_{\max}$ used without ensemble blending.
  \item \textbf{NO\_ENS\_RIDGE}: Both ensemble and Ridge correction disabled simultaneously.
  \item \textbf{NO\_HYBRID}: Hybrid $C_{\max}$ selector (adaptive-weight blend of ODE and analytical
    1-compartment predictions) replaced by raw ODE $C_{\max}$.
  \item \textbf{BARE}: All post-hoc corrections disabled; raw ODE output only.
\end{itemize}
