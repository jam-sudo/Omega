# Roadmap

1. **DDI expansion**
   - Time-varying inhibitor concentrations
   - Enzyme induction/suppression modules
2. **Renal model refinement**
   - Filtration + secretion + reabsorption split
3. **Liver model refinement**
   - Multi-zonal metabolism and transporter effects
4. **Population simulation**
   - Covariate distributions and virtual populations
5. **QSP integration**
   - Pathway-level downstream biomarkers
6. **Calibration and validation**
   - Fit against curated PK/PD datasets and external benchmarks
