# Plan INNO-1: Clinical Validation First, Then Fix

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Honest clinical AAFE < 2.2 (stretch < 2.0) on 24 gold drugs with all-clinical reference data

**Architecture:** Complete clinical reference data for all gold drugs, diagnose root causes of prediction errors via ADME comparison + sensitivity analysis, apply targeted structural fixes ranked by diagnosis, then retrain ML corrections against clinical targets.

**Tech Stack:** PK-DB API, OpenFDA, PubMed literature, XGBoost (corrections), RDKit (features), scipy (sensitivity)

**Baseline (honest, 2026-03-18):**
- Mixed (9 clinical + 15 synthetic): Cmax AAFE 1.858 [1.58, 2.21], 71% 2-fold
- Real-data-only (9 drugs): AAFE ~2.40, 33% 2-fold
- Key failures: midazolam 5.01x, warfarin 5.24x, caffeine 3.22x, fluconazole 3.04x

**Why the old plan is invalid:**
Old AAFE 1.646 was measured against synthetic CSVs generated from Omega's own 1-cpt model. This was circular — "agreement with ourselves", not clinical validation. All optimization must now target clinical reference data.

## Phase C: Targeted Structural Fixes (ranked by B.3)

**Principle:** One fix at a time. Benchmark after each. Error cancellation monitor on every change.

### Acceptance criteria for each fix:
1. Mean AAFE decreases (vs clinical reference)
2. ≤ 2 drugs regress in fold-error
3. No drug newly exceeds 3x fold-error
4. If AAFE unchanged → revert (no pointless complexity)

### Expected fix candidates (order determined by B.3 diagnosis):

**Candidate C.1: Berezhkovskiy Kp cap at low fup**
- Target: warfarin (5.24x), other highly-bound drugs
- Mechanism: Kp overestimation when fup < 0.01 (known Berezhkovskiy limitation)
- Approach: cap Kp_uu or use alternative (Poulin-Theil) for fup < threshold

**Candidate C.2: CYP3A4 gut wall Fg recalibration**
- Target: midazolam (5.01x)
- Mechanism: gut wall fix (Phase 3a.1) may over-extract for true CYP3A4 substrates
- Approach: adjust CLint_gut scaling for CYP3A4-positive drugs

**Candidate C.3: Vd empirical correction**
- Target: caffeine (3.22x)
- Mechanism: Kp over-prediction for hydrophilic drugs (low logP, high water solubility)
- Approach: logP-dependent Kp scaling or XGBoost VDss integration

**Candidate C.4: CLint scaling for low-CL drugs**
- Target: fluconazole (3.04x)
- Mechanism: XGBoost CLint over-predicts for drugs with very low intrinsic clearance
- Approach: CLint floor or nonlinear scaling in IVIVE

### Per-fix task template:

- [ ] **Step 1:** Write failing test (drug Cmax fold-error > current threshold)
- [ ] **Step 2:** Implement fix
- [ ] **Step 3:** Run full benchmark (clinical reference)
- [ ] **Step 4:** Check acceptance criteria (AAFE ↓, ≤2 regressions, no new >3x)
- [ ] **Step 5:** If accept → commit. If reject → revert and document why.
- [ ] **Step 6:** Update error cancellation monitor

### Task D.3: Applicability domain gating

**Files:**
- Modify: `src/omega_pbpk/pipeline/__init__.py` (ML correction block)
- Modify: `src/omega_pbpk/ml/corrections/adaptive_conformal.py`

**Gating logic:**
- Compute Tanimoto similarity to nearest training drug
- If similarity > threshold (e.g., 0.7): trust base pipeline, correction weight → 0
- If similarity < threshold: apply full correction
- Smooth transition in between (sigmoid weighting)

- [ ] **Step 1:** Add similarity computation to pipeline ML correction block
- [ ] **Step 2:** Implement sigmoid gating: `w = sigmoid((threshold - similarity) * steepness)`
- [ ] **Step 3:** Correction = w * raw_correction
- [ ] **Step 4:** Tune threshold on LOO CV (grid search 0.3-0.8)
- [ ] **Step 5:** Benchmark with gated ML corrections
- [ ] **Step 6:** Commit
