## 5대 혁신 구현 내역

### 혁신 1 — Fluconazole CLint 앵커 교정
- **파일**: `src/omega_pbpk/ml/models/adme/xgboost_clint.py`
- **문제**: Fluconazole CLint 과잉예측 (8.18 → 실측 기준 ~2.0 µL/min/10⁶)
- **원인**: 이전 앵커가 CL_total=2.36 L/h 기준 역산 (실제 FDA label: 1.18 L/h — 2배 오류)
- **수정**: `("OC(Cn1cncn1)(Cn1cncn1)c1ccc(F)cc1F", 2.0)` 앵커 추가
  - 80% 신장 배설 → CLh_hepatic ≈ 0.47 L/h → back-calc CLint ≈ 1.8
- **결과**: XGBoost CLint 8.18 → 2.381, fluconazole 3.06x → 2.81x

### 혁신 2 — 신장 CL 재흡수 공식 개선
- **파일**: `src/omega_pbpk/pipeline/__init__.py`, `_estimate_renal_clearance()`
- **문제**: 중극성 분지(logP<2.0, TPSA>74)에서 재흡수 과소평가
  - 구형식: `reabsorption = logP/2.0` → fluconazole(logP=0.74): 37% (실제 70%)
- **수정**: `reabsorption = 0.35 + logP×0.50` (logP>0인 경우)
  - fluconazole: 37% → 72% (실제 70% ✓)
  - CLr: 4.04 → 1.79 L/h (실제 1.89 L/h ✓)
- **결과**: fluconazole CL_total 오류 감소; gold-24 유일하게 이 분지에 해당

### 혁신 3 — Gut Wall CYP3A4 임계값 2.0→2.6 상향
- **파일**: `src/omega_pbpk/pipeline/__init__.py`, `_GUT_WALL_CLint3A4_THRESHOLD`
- **문제**: warfarin의 clint_3a4=2.553이 임계값 2.0을 초과 → 위양성 gut extraction
  - warfarin은 CYP2C9 기질 (CYP3A4 아님!) → gut wall 추출 적용 오류
- **수정**: 임계값 2.0 → 2.6 µL/min/pmol
  - warfarin(2.553): 2.6 미만 → 제외 ✓
  - midazolam(3.096)/verapamil(4.767)/fluoxetine(3.481): 여전히 포함 ✓
- **결과**: warfarin 3.82x → 1.89x (>3-fold → 2-fold 이내!)

### 혁신 4 — XGBoost VDss 기준 앵커 시스템 신설
- **파일**: `src/omega_pbpk/ml/models/adme/xgboost_vdss.py`
- **근거**: VDss 앵커는 "XGBoost 과대예측 AND Cmax 과소예측" 동시 조건에서만 안전
  - ibuprofen(VDss 9.8배 과대예측이나 Cmax 완벽): 앵커 금지 — 오류 상쇄
  - verapamil/propranolol(VDss 과소예측): 앵커 금지
- **추가 앵커**:
  ```python
  ("Clc1ccc2c(c1)C(=NCc1nccn1C)c1ccccc1-2", 0.70),  # midazolam
  ("CC(=O)CC(c1ccccc1)c1c(O)c2ccccc2oc1=O", 0.13),   # warfarin
  ```
  - 8× 가중치, CV는 TDC 데이터만 사용
- **결과**: midazolam VDss 1.96→0.73 L/kg, warfarin VDss 0.63→0.15 L/kg
  - warfarin: Berezhkovskiy(60L) > XGB(9.1L)×4.5=41L → VDss 보정 발동 → Cmax ↑

### 혁신 5 — VDss 보정 임계값 4.0→4.5 상향
- **파일**: `src/omega_pbpk/pipeline/__init__.py`, `_vd_berez > _vd_xgb_L * 4.5`
- **문제**: warfarin VDss 앵커 추가 후 fluoxetine 회귀
  - XGBoost VDss 잔차효과로 fluoxetine VDss 462L→400L
  - Berezhkovskiy/XGBoost 비율: 1680/400=4.2x — 임계값 4.0 초과 → 보정 발동
  - 보정 발동 시 400L 대신 ODE 혼합값 사용 못 함 → fluoxetine 1.90x→1.98x 악화
- **수정**: 임계값 4.0 → 4.5
  - fluoxetine(4.2x): 4.5 미만 → 보정 미발동 → ODE 혼합 복구 ✓
  - midazolam(26x)/warfarin(184x+): 여전히 보정 발동 ✓
- **결과**: fluoxetine 1.98x → 1.29x 복구

## 다음 혁신 방향 (Phase 3b — 미착수)

### Priority 1: CLint_gut 아키텍처 수정
- **현재 버그**: `clint_L_per_h` (역산된 hepatic CL, 22-223× CLh_target) × K=1.7 → CLint_gut 과잉
- **수정 방향**: gut-wall CLint는 hepatic IVIVE와 독립적으로 산출해야 함
  - Fg = Q_gut / (Q_gut + Fg_CL_int) 에서 Fg_CL_int는 intestinal CYP3A4 함량 기반
  - 필요 조건: fup 수정 선행 (K 재보정 fup-coupled)
- **기대 효과**: midazolam 3.99x → ~2x 감소 가능

### Priority 2: Fluconazole Berezhkovskiy Vd 수정
- **현재**: neutral 분류 + logP=0.74 → Kp_adipose=2.51 → Vd~66L (실제~45L)
- **탐색 방향**: amphoteric compound_type 추가 (triazole+hydroxyl)
  - D-fix를 양쪽이온에도 확장?
  - 조심: D-fix가 acids에만 검증됨 — zwitterion 적용 시 별도 검증 필요

### Priority 3: ML Corrections 재훈련
